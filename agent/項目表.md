# 項目與依賴關係

| 路徑 | 用途 | 依賴 |
| --- | --- | --- |
| `install.sh`、`scripts/test_install.py` | VPS Release 安裝與更新；角色隔離、校驗、失敗回復的 TDD | Bash、curl、sha256sum、systemd；測試以暫存目錄隔離主機命令 |
| `.github/workflows/release.yml`、`scripts/release_smoke.py` | 標籤自動發布已驗證資產；真實 Release systemd 安裝與上報 | 可重用 Linux CI、GitHub Releases、乾淨 Ubuntu runner |
| `agent/release-validation.md` | v0.1.0 發布、安裝器 TDD 與真實 systemd 驗收證據 | Release 資產、workflow 日誌 |
| `.github/workflows/linux-ci.yml` | 真實 Ubuntu 完整 race／PostgreSQL／Agent smoke、前端與 ARM64 建置 | GitHub Actions、PostgreSQL 17 service、既有測試 |
| `agent/ci-validation.md` | 遠端 run、提交與 Linux／PostgreSQL 實測結果 | GitHub Actions 日誌與測試 JSON |
| `agent/question.md` | 使用者決策與 TDD 驗收標準 | 使用者回覆 |
| `agent/deep_todos.md` | 完整任務歷史 | 開發與驗證結果 |
| `agent/memory.md` | 重要操作與決策紀錄 | 工作區操作 |
| `agent/項目表.md` | 檔案用途與依賴關係 | 專案結構 |
| `agent/architecture.md` | 模組邊界、實作決策與測試週期 | 需求與程式 |
| `agent/validation.md` | RED／GREEN、建置、整合與限制證據 | 各測試與工具結果 |
| `agent/audit-2026-09-15.md` | 使用者要求的深入稽核、缺陷重現、修復與最新驗證 | 各 audit 測試與 binary／Playwright 驗證 |
| `README.md` | 建置、啟動、設定、告警與搬移說明 | 下列程式與部署範本 |
| `go.mod`、`go.sum` | Go 版本與固定依賴 | Go、gopsutil、pgx、modernc SQLite、x/crypto |
| `cmd/server/main.go` | HTTP 主程式、背景工作與正常關閉 | server、store、web |
| `cmd/server/main_test.go` | 真實子程序監聽失敗與非零退出回歸 | Go 測試子程序、暫存 SQLite |
| `cmd/agent/main.go` | Agent 環境變數／旗標與終止訊號 | collector |
| `internal/model/model.go` | 原始樣本、速率、規則、告警狀態轉換 | Go 標準庫 |
| `internal/model/model_test.go` | 輸入／計數器／規則／告警測試 | model |
| `internal/model/audit_test.go` | 告警新鮮樣本、未知 CPU、規則變更連續性 | model |
| `internal/collector/collector.go` | 原始 OS 採集與限時 HTTP 上報 | gopsutil、model |
| `internal/collector/run.go` | 可取消採集循環與間隔下發 | collector |
| `internal/collector/*_test.go` | 真實採集、HTTP 契約與取消測試 | httptest、collector |
| `internal/store/store.go` | 共用 SQL CRUD、歷史分桶、跨庫複製 | database/sql、SQLite、pgx、model |
| `internal/store/runtime.go` | URL 優先序、重啟搬移與設定檔切換 | store、檔案系統 |
| `internal/store/maintenance.go` | 通知佇列、退避、保留期限與刪除 | store |
| `internal/store/*_test.go` | SQLite 回歸及選用 PostgreSQL 整合 | 暫存 SQLite／隨機 PostgreSQL schema |
| `internal/server/server.go` | Session、權限、主機／上報／設定 API、離線評估 | model、store、bcrypt |
| `internal/server/notify.go` | Webhook／Telegram 限時投遞與佇列處理 | net/http、store |
| `internal/server/*_test.go` | 權限、上報、通知、排序與慢請求回歸 | httptest、暫存 SQLite |
| `internal/server/audit_test.go` | Session 到期、HTTPS Cookie、bcrypt／慢回應併發、斷線空窗 | gated verifier／ResponseWriter、server／store |
| `internal/store/audit_test.go` | URL 邊界、環境優先、中途寫入失敗的交易回滾 | SQLite trigger、暫存設定檔 |
| `web/embed.go`、`web/embed_test.go` | 嵌入靜態前端並測試路由／favicon | web/dist、embed、net/http |
| `web/src/App.vue` | 總覽、登入、詳情、告警、主機與全域設定 | Vue、API、Trend、RuleFields |
| `web/src/Trend.vue` | 五種歷史指標 SVG 折線圖 | types、Vue |
| `web/src/RuleFields.vue` | 全域／單機共用規則欄位 | types、Vue |
| `web/src/types.ts` | API 與前端資料型別 | 後端 JSON 契約 |
| `web/src/main.ts`、`web/src/style.css` | Vue 啟動與響應式深色介面 | App、CSS |
| `web/src/App.test.ts` | 私人／公開、搜尋、趨勢、管理、覆寫、同名告警測試 | Vitest、Vue Test Utils、jsdom |
| `web/src/App.audit.test.ts` | 逾期權限、過時回應、取消、刪除與導覽競態 | fake timers、延遲 fetch、App |
| `web/index.html`、`web/public/favicon.svg` | HTML 入口、語系與本地圖示 | Vite |
| `web/package.json`、`web/package-lock.json` | 前端依賴與腳本 | npm |
| `web/vite.config.ts`、`web/tsconfig.json` | 前端建置、開發代理與嚴格型別設定 | Vite、Vitest、TypeScript |
| `scripts/smoke.py` | 隔離執行檔整合、真實上報與限時瀏覽器測試服務 | Python 標準庫、bin 執行檔 |
| `scripts/verify_go_tests.py`、`scripts/test_verify_go_tests.py` | CI JSON 結果門檻與 5 項回歸；禁止案例略過、失敗與必要測試缺席 | Python 標準庫、Go test JSON |
| `deploy/README.md` | Linux 安裝、反向代理與備份說明 | 主程式／Agent |
| `deploy/*.service` | systemd 範本 | /opt/spm、/etc/spm |
| `deploy/*.env.example` | 管理員／Agent 環境變數範例 | shell 或 systemd EnvironmentFile |
| `bin/` | 六個建置產物，已忽略版控 | Windows amd64、Linux amd64／arm64 |
| `web/dist/`、`web/node_modules/` | 前端生成檔／依賴，已忽略版控 | npm build／ci |
| `.gitignore` | 排除執行資料、憑證檔及建置產物 | 專案目錄 |

此 `agent/` 目錄供專案紀錄使用；正式採集程式位於 `cmd/agent/` 與 `internal/collector/`。Agent 的依賴樹不包含 store、SQLite、PostgreSQL 或 Vue。
